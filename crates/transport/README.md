# radroots-transport

This is the README for `radroots_transport`, which provides transport-neutral
delivery models for the `radroots` core libraries.

## Overview

 * transport kind, implementation state, and status model types;
 * target URI, target fingerprint, target set, request, and receipt contracts;
 * deterministic target fingerprints based on transport kind and canonical
   target URI;
 * portable shared models with optional `serde` support.
